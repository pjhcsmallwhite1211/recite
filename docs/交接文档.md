## 1. 架构

```
参考原型(只读)                    本 App(app/src/main/java/com/recite/words/)
code_20260803.html  ┐
test.html           ├──移植──►   data/    模型 + JSON 持久化 + Repository   ← 纯 Kotlin
display.html        ┘            domain/  词表解析、假词生成、四选一构造     ← 纯 Kotlin
                                 speech/  TextToSpeech 封装
                                 ui/      Compose 两标签页界面
                                      │
浏览器 localStorage  ──格式等同──►   filesDir/recite-data.json
```

**数据管线**(单向):用户操作 → `ReciteRepository`(唯一写入口,写后立即落盘) →
`StateFlow<ReciteData>` → Compose 重组 → `filesDir/recite-data.json`。

**为什么不用 Room**:数据量在数千词量级,单 JSON 文件全量读写足够;更重要的是
文件字段与网页版备份完全一致(`wordBookList` / `currentBookId` / `wrongWordMap`),
网页版导出的备份可以**直接导入 App**,反之亦然。

## 3. 项目决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 技术路线 | Kotlin + Jetpack Compose(原生) | 用户选定;长期最好维护 |
| 构建版本组合 | AGP 9.0.1 / Gradle 9.8.0 / Kotlin 2.3.20 / Compose BOM 2026.03.01 | 直接取自官方 `android create empty-activity` 模板,已实测可构建 |
| 持久化 | 单 JSON 文件 + kotlinx.serialization | 与网页版备份格式互通 |
| V1 范围 | 卡片背词 + 多选测试(两标签页共享状态) | 两个原型共用同一套数据结构,合做一个 App 增量成本低 |
| 安装位置 | SDK / Gradle 缓存 / Studio 全在 D 盘 | 用户要求,且 C 盘仅剩 44GB |
| 目标机型 | Redmi Note 8;minSdk 24 / targetSdk 36 | 真机 Android 9/10 |

## 4. 踩坑(都已解决,记录以备复现)

1. **AGP 9 起 Kotlin 支持内置**:应用 `org.jetbrains.kotlin.android` 会直接构建失败,
   报 `AgpWithBuiltInKotlinAppliedCheck`。解法:移除该插件,保留
   `com.android.application` + `org.jetbrains.kotlin.plugin.compose` +
   `org.jetbrains.kotlin.plugin.serialization`,Kotlin 配置改用 `kotlin { jvmToolchain(17) }`。
2. **`sdkmanager` 已弃用**:新版 cmdline-tools 提示改用 `android.exe`(`android sdk install` /
   `android sdk list`)。`--licenses` 也不再需要。
3. **本机 `JAVA_HOME` 指向 JDK 8**:Android 构建需要 JDK 17+。解法:在 `gradle.properties`
   写死 `org.gradle.java.home=D:/Program Files/Java/jdk-21`;并显式声明
   `org.gradle.java.installations.paths`(JDK 装在 D 盘,不在 Gradle 默认扫描路径内,
   `jvmToolchain(17)` 否则找不到)。
4. **Gradle 官方源在国内极慢**(实测 ~5MB/min)。解法:wrapper 的 `distributionUrl` 与手动下载
   都改用腾讯镜像 `mirrors.cloud.tencent.com/gradle/`,实测 144MB / 7 秒。
5. **Android Studio 安装器需要管理员权限**:非提权启动返回 1223(`ERROR_CANCELLED`)。
   解法:见第 5 节。
6. **`adb devices` 为空**:手机未连或未开 USB 调试。小米机型除「开发者选项 → USB 调试」外,
   还需打开「USB 调试(安全设置)」。
7. **写 `.cmd` 脚本必须同时管住两件事:GBK 编码 + CRLF 行尾**(两个坑都踩过,症状相似但根因不同,
   两次都表现为报一串「不是内部或外部命令」):
   - **行尾(主因)**:`cmd.exe` 的批处理解析器要求 **CRLF**。文件若只有 LF,含多行 `if (...)`
     块与 `goto` 标签的脚本会因字节偏移 seek 错位,把文件中段当成命令执行,输出半截乱码命令。
   - **编码**:批处理按系统 ANSI 代码页(简体中文 = 936)读取,必须用 **GBK** 保存;UTF-8 会让
     中文变乱码。**不要**指望在批处理里用 `chcp 65001` 补救(解析代码页不可靠)。
   - 正确写法:先把内容归一为 CRLF,再用 GBK 落盘 ——
     `$c = ($c -replace "`r`n","`n") -replace "`n","`r`n"`,
     `[IO.File]::WriteAllText($p, $c, [Text.Encoding]::GetEncoding(936))`。
   - **验证方式**:以非管理员空跑,并强制 CP=936 ——
     `'' | cmd /c "chcp 936 >nul & `"$p`" > out.txt 2>&1"`,再用 GBK 读回 `out.txt`。
     ⚠ 直接看 PowerShell 捕获的 stdout 会被 **PS7 的 UTF-8 控制台**误导(显示成「锟斤拷」),
     那不是脚本的问题。
9. **360 安全卫士会静默拦下无界面的批量操作**:本机装有 360(`HipsDaemon` / `HipsTray` 常驻)
   与 `AlibabaProtect`。表现为:`uninstall.exe /S` 静默卸载**一个文件都没删**(目录时间戳不变、
   `%TEMP%` 里无 `~nsu.tmp` 痕迹),紧接着安装器返回 1223(`ERROR_CANCELLED`)。
   **判据**:`Get-Process | ? ProcessName -match 'Hips|360'`;静默命令行操作若"看起来成功但
   状态没变",优先怀疑 HIPS。**对策**:改用图形化卸载/安装(弹窗时点「允许本次操作」),
   或临时关闭主动防御,不要反复重试静默命令。
10. **`adb shell input tap` 会返回 `exit=137`(SIGKILL)但触摸事件其实已发出**:MIUI 会杀掉
    `input` 进程。**判据**:退出码 137 但界面确实响应了。**对策**:不要以退出码判断点击成败,
    改为点击后 dump 界面状态确认;必要时重试。排查时不要被这个假失败带偏。
11. **Material3 `Button` 默认 `contentPadding` 是 24dp(水平)**:4 个按钮挤一行时会吃掉文字宽度,
    中文按钮("⬅️ 上一个")会被折成两行。**对策**:显式收紧
    `contentPadding = PaddingValues(horizontal = 4.dp, vertical = 10.dp)` 并给文字加 `maxLines = 1`。
12. **`~/.android/debug.keystore` 被重建会导致 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`**:
    在 Android Studio 里 Gradle 同步/构建过之后,命令行再 `adb install -r` 会因签名不一致失败。
    **判据**:`Get-Item ~/.android/debug.keystore | Select CreationTime` 晚于 App 的 `firstInstallTime`。
    **对策**:先 `adb uninstall <包名>` 再装(会丢 App 数据);长期方案是改用固定的 release 签名。
    另:**命令行与 Studio 不要混着装同一个 App**。
13. **`.properties`(如 Studio 的 `bin/idea.properties`)里不要写中文**:Java 按 Latin-1 读取,
    中文会变乱码;而且替换时若把注释与赋值挤到同一行,会把配置整行注释掉导致不生效。
    **对策**:这类文件只用 ASCII 注释,改完按字节检查非 ASCII 数量为 0。
8. **UAC 无法从后台非交互进程弹出**:`Start-Process -Verb RunAs` 在后台 job 中发起提权会被
   Windows 直接按「取消」处理并返回 1223(`ERROR_CANCELLED`),**UAC 窗口根本不会出现**。
   提权操作必须由用户从资源管理器发起(右键 →「以管理员身份运行」)。
